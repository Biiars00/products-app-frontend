# Products App Frontend

> Este é o repositório da interface do sistema de Gestão de Produtos ([products-app-backend](https://github.com/Biiars00/products-app)), desenvolvido utilizando **React**. O projeto fornece um front-end amigável para gerenciar produtos, permitindo operações como listagem, adição, edição e remoção de itens do inventário.​

## Funcionalidades
- **Listagem de Produtos:** Visualize todos os produtos disponíveis no inventário.​
- **Adição de Produtos:** Adicione novos produtos ao inventário.​
- **Edição de Produtos:** Atualize as informações dos produtos existentes conforme necessário.​
- **Remoção de Produtos:** Exclua produtos que não são mais necessários.​

## Tecnologias Utilizadas

- **React:** Biblioteca principal para construção da interface do usuário.​
- **Axios:** Cliente HTTP para comunicação com a API backend.​

## Pré-requisitos

Antes de iniciar o projeto, certifique-se de ter instalado em sua máquina:
- **Node.js:** Ambiente de execução JavaScript necessário para rodar o projeto.​

## Instalação

1. Clone o repositório:
    ```
    git clone https://github.com/Biiars00/products-app-frontend.git
    ```

2. Navegue até o diretório do projeto:
    ```
    cd products-app-frontend
    ```

3. Instale as dependências:
    ```
    npm install
    ```

## Rodando o projeto

No terminal, rode o comando: `npm start`
